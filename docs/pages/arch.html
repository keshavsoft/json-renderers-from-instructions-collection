Architecture & Execution Pipeline

From user configuration to Virtual DOM synthesis and real DOM mounting.

Execution Flow Pipeline

+-----------------------------------------------------------+ | User Config { data, columns, renderers, targetHtmlId } | +-----------------------------------------------------------+ │ ▼ [ 1. Input Guard Validation ] (json-renderers-guard) │ ▼ [ 2. Composite Spec Builder ] (src/v1/buildSpec.js) │ │ ├─ [Child Spec 1] ├─ [Child Spec 2] │ (buildSingleSpec)│ (buildSingleSpec) ▼ ▼ [ runInstructions ] + [ runOptions ] (Transforms schema into VDOM) │ ▼ [ 3. Composite Virtual JSON DOM Tree ] { tagName: "div", children: [...] } │ ▼ [ 4. Mount to Real DOM ] (@keshavsoft/json-to-dom) │ ▼ [ 5. Global Runtime Registry ] (globalThis.ks.jsonRenderers.fromInstructionsCollection)

Key Execution Stages

1. Input Contract Validation

Guards ensure columns, data, and renderers are valid arrays before mounting.

2. Composite Layout Assembly

Assembles child specs vertically (d-flex flex-column gap-4) or horizontally (row g-4).

3. Virtual DOM Compilation

Fetches the blueprint from spec-repo and merges data into a lightweight virtual DOM tree.

4. DOM Mounting

Mounts into targetHtmlId in replace, append, or prepend mode via @keshavsoft/json-to-dom.
