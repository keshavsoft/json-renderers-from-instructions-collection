Types Reference

Available Component Types

All components defined in spec-repo and supported by the orchestrator.

Table Component Category

The table category in spec-repo provides variants for complete tables as well as sub-structures for performance-critical partial updates.

Type Identifier Description Supported Options
table.simple Full data table with colgroup, thead, tbody, and tfoot. showSerial, showSearch, showOptions
table.bodyOnly Produces solely <tbody> row elements. Used for instant filter updates without resetting header or search input. showSerial, showOptions
table.headerOnly Produces only colgroup and thead. Useful for fixed sticky headers. showSerial, showOptions
table.footerOnly Produces only tfoot row cells for summary or quick-entry actions. showSerial, showOptions
Options Explained:
  • showSerial: true — Unshifts serial width to colgroup, prepends # header to thead, serial index (1, 2, ...) to tbody rows, and footer serial cell.
  • showSearch: true — Injects a live search bar container (id="tableSearch") docked on top of the table.
  • showOptions: true — Pushes an action button column (.ks-btn-show) for row selection and interaction events.
Example:
render({
    data,
    columns,
    targetHtmlId: "container",
    renderers: [
        { 
            type: "table.simple", 
            options: { showSerial: true, showSearch: true, showOptions: true } 
        }
    ]
});

Form Category (form.simple)

Dynamically generates a responsive input form based on column definitions with labels, input boxes, and submit buttons.

{
    type: "form.simple",
    options: {
        title: "Create New Item",
        submitLabel: "Save Record"
    }
}

Select & DataList Categories

select.simple

Renders a styled <select> element populated with distinct values or column options. Ideal for category filtering docked above tables.

dataList.simple

Renders an HTML5 <datalist> element to provide native autocomplete suggestion dropdowns for associated text inputs.
