KeshavSoft Dependent Libraries

The short story of each specialized KeshavSoft library powering this orchestrator, with direct repository navigation.

The Modular Micro-Library Philosophy

Instead of a monolithic framework, KeshavSoft separates concerns into laser-focused, single-responsibility micro-libraries. Each library handles one exact stage of turning pure data schemas into real, high-performance DOM nodes:

Guard Validation → Blueprint Registry → Instruction Engine → Option Enhancer → DOM Mounting
spec-repo ^1.8.1
View Repository →

The Blueprint Repository

Stores canonical JSON specifications for all UI components (table.simple, table.bodyOnly, form.simple, select.simple). It defines the skeletal DOM structure, CSS classes, and instruction templates without any hardcoded rendering logic.

Role: Single source of truth for component schemas and option transforms.
json-renderers-guard ^1.5.3
View Repository →

The Contract Enforcer

Performs strict runtime assertions on incoming configuration objects. It verifies that data, columns, and renderers conform to the collection contract before execution, preventing silent runtime failures.

Role: First-line validation gate at the start of render().
json-renderers-run-instructions ^1.5.4
View Repository →

The Instruction Execution Engine

Executes declarative instruction sets (single, double, rowOnColumn, columnOnRow) mapped from spec-repo. It transforms raw column and data arrays into structured Virtual DOM trees.

Role: Generates the base virtual DOM tree.
json-renderers-run-options ^1.1.1
View Repository →

The Dynamic Feature Enhancer

Modifies and enriches base virtual DOM trees with user-configured feature flags. It injects serial number columns, search input bars, and action buttons into headers, bodies, and footers.

Role: Applies showSerial, showSearch, and showOptions.
@keshavsoft/json-to-dom ^42.1.5
View Repository →

The Native DOM Mounter

A blazing fast Virtual JSON DOM to Native HTML DOM compiler. It walks the compiled JSON spec tree, creates real HTML elements, sets attributes, binds roles, and mounts them into the document container.

Role: Real DOM conversion and insertion (replace, append, prepend).
