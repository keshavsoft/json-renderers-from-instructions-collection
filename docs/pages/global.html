The registerGlobal Story

How the library seamlessly exposes itself on globalThis.ks for zero-build HTML usage.

The Origin Story

Zero-Config Browser Accessibility

Not every frontend project uses Webpack, Vite, or a bundler. In many legacy portals, micro-frontends, or fast proof-of-concepts, loading a library via a <script> tag and having it immediately available on globalThis is essential.

To enable this without polluting global scope with arbitrary variables, KeshavSoft registers under the standardized globalThis.ks namespace hierarchy: 

// src/v1/registerGlobal/index.js
import meta from "./meta.js";

export const registerGlobal = (inDefinition) => {
    const localDefinition = inDefinition;

    if (typeof globalThis === "undefined" || !localDefinition) return;

    globalThis.ks ??= {};
    globalThis.ks.jsonRenderers ??= {};

    globalThis.ks.jsonRenderers.fromInstructionsCollection = {
        meta,
        render: localDefinition
    };
};

How to Use in Any Web Page

<script src="https://cdn.example.com/docs/dist/v1/min.js"></script>
<script>
    // Immediately available globally
    const render = globalThis.ks.jsonRenderers.fromInstructionsCollection.render;
    render({ ... });
</script>
