v1.0.0 Zero Boilerplate 1-Statement Render

Declarative Composite Multi-Renderer

Short Story: Traditional UI requires writing separate HTML boilerplate, form inputs, and table loops for every screen. This orchestrator unifies them: given 1 shared schema (columns) and 1 dataset (data), it mounts multiple coordinated components (Form on top + Table below, or Select + Table) in 1 single statement.

Component blueprints originate from spec-repo and execute via KeshavSoft's modular micro-libraries.

1-Statement Quick Start

import render from "json-renderers-from-instructions-collection";

// Single Source of Truth: Columns & Data
const columns = [
    { field: "itemName", displayName: "Item Name", type: "string" },
    { field: "category", displayName: "Category", type: "string" },
    { field: "baseUnit", displayName: "Base Unit", type: "string" }
];

const data = [
    { itemName: "Rice Raw Non-Basmathi", category: "Grains", baseUnit: "Kgs" },
    { itemName: "Cooking Oil Sunflower", category: "Oils", baseUnit: "Litres" }
];

// 1 Statement Composite UI Render
render({
    data,
    columns,
    targetHtmlId: "dom-render-container",
    appendPosition: "replace",
    renderers: [
        { type: "form.simple", options: {} },
        { 
            type: "table.simple", 
            options: { showSerial: true, showSearch: true, showOptions: true } 
        }
    ]
});
