Architecture & Execution Pipeline

Understand how declarative instruction sets compile into virtual DOM nodes and mount smoothly into the DOM tree.

Execution Flow Pipeline

+-----------------------------------------------------------+ | User Config { data, columns, renderers, targetHtmlId } | +-----------------------------------------------------------+ │ ▼ [ 1. Input Guard Validation ] (json-renderers-guard) │ ▼ [ 2. Composite Spec Builder ] (src/v1/buildSpec.js) │ │ ├─ [Child Spec 1] ├─ [Child Spec 2] │ (buildSingleSpec)│ (buildSingleSpec) ▼ ▼ [ runInstructions ] + [ runOptions ] (Transforms schema into VDOM) │ ▼ [ 3. Composite Virtual JSON DOM Tree ] { tagName: "div", children: [...] } │ ▼ [ 4. Mount to Real DOM ] (@keshavsoft/json-to-dom) │ ▼ [ 5. Global Runtime Registry ] (globalThis.ks.jsonRenderers.fromInstructionsCollection)

The 5 Key Stages

1. Input Contract Validation

Before any DOM mutations or processing occurs, guardFunc from json-renderers-guard performs type assertion on the incoming configuration object. It ensures that renderers, columns, and data match expected structures, preventing silent failures.

2. Composite Spec Assembly (buildSpec.js)

Iterates over each renderer entry in config.renderers. It passes the shared or individual columns and data to buildSingleSpec for individual component compilation.

The resulting specs are grouped into a parent container. If layout: "horizontal" is specified, it uses Bootstrap's row g-4; otherwise, default vertical layout uses d-flex flex-column gap-4.

3. Virtual DOM Transformation (buildSingleSpec.js)

Each individual component undergoes two micro-passes:

  • Instruction Engine (json-renderers-run-instructions): Executes declarative rule instructions (e.g. single, double, rowOnColumn, columnOnRow) mapped from spec-repo to generate the core DOM representation.
  • Feature Enhancer (json-renderers-run-options): Enriches the tree with user-requested toggles, such as serial number columns, search input controls, and action buttons.

4. Mounting to the Real DOM (@keshavsoft/json-to-dom)

The combined Virtual JSON DOM is delivered to jsonToDom. The engine locates the element specified by targetHtmlId and applies the designated mount mode (replace, append, or prepend).

5. Global Runtime Registration

Enables zero-friction usage across external scripts, browser bundles, and micro-frontends by attaching itself to the global environment: 

globalThis.ks.jsonRenderers.fromInstructionsCollection = {
    meta: { name, version, description },
    render: render
};
