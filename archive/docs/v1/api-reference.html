API Reference

Complete parameter definitions, defaults, return types, and schemas for the library.

render(config)

Primary default export. Renders a collection of coordinated components into the DOM in 1 statement.

Parameters
Parameter Type Default Description
config.targetHtmlId string Required The ID of the DOM container where the composite UI will be mounted.
config.data Array<Object> [] The Single-Source-of-Truth dataset.
config.columns Array<Object> [] Array of column/field schema specifications.
config.renderers Array<Object|string> [] List of component renderers to generate and orchestrate.
config.layout string "vertical" Layout arrangement: "vertical" (stacked) or "horizontal" (Bootstrap grid row).
config.appendPosition string "replace" DOM mount position: "replace", "append", or "prepend".
config.classToApply string "" Optional custom CSS classes appended to the root container.
config.showLog boolean false Print verbose debugging information to the console.
Returns

HTMLElement — The mounted native DOM element container.

config.renderers[i] Item Object

Defines each component inside the collection. Can be passed as a string (e.g. "form.simple") or as an object:

Key Type Default Description
type string Required Category and variant identifier, e.g. "table.simple", "form.simple", "table.bodyOnly".
options Object {} Feature flags, such as showSerial, showSearch, or showOptions.
data Array<Object> Inherits parent Per-component dataset override if different from root data.
columns Array<Object> Inherits parent Per-component column schema override if different from root columns.

buildSpec(config) & buildSingleSpec(config)

For headless compilation, SSR, or virtual DOM pipeline integration without mounting to the DOM:

import { buildSpec, buildSingleSpec } from "json-renderers-from-instructions-collection";

// Compile entire composite tree
const compositeSpec = buildSpec({
    renderers: [{ type: "form.simple" }, { type: "table.simple" }],
    columns,
    data,
    layout: "vertical"
});

// Compile a single element tree
const singleTableSpec = buildSingleSpec({
    type: "table.simple",
    columns,
    data,
    options: { showSerial: true }
});
