Components & Feature Options

Supported component renderers, schema conventions, and configuration options.

Renderer Types

Renderer Type Description Common Role
table.simple Full data table with <table>, <thead>, <tbody>, and <tfoot>. Main data grid view.
table.bodyOnly Generates exclusively <tr> body rows without table wrappers. High-speed filter/search row replacement.
form.simple Dynamic data input form with labels and fields generated from column schema. Record creation & editing.
select.simple Standalone <select> dropdown picker populated from schema or records. Category filtering or single-item select.
dataList.simple HTML5 <datalist> suggestion element for autocomplete search. Search input autocompletion.

table.simple Options

Customizes the behavior and layout of the rendered table component:

Option Key Type Default Behavior
showSerial boolean false Prepends a serial numbering column (#, index 1-based) to both header and rows.
showSearch boolean false Adds a search input field atop the table with id="tableSearch".
showOptions boolean false Appends an actions column with view button (.ks-btn-show) for row selection.
Example Usage:
{
    type: "table.simple",
    options: {
        showSerial: true,
        showSearch: true,
        showOptions: true
    }
}
