Short Note: What is this & How does it work?

In traditional web apps, rendering a form and a table requires writing independent HTML templates, managing synchronization loops, and duplicating field bindings.

json-renderers-from-instructions-collection eliminates all of that by introducing a declarative multi-renderer pipeline:

Step 1

Input Guard Assertions

Validates configuration using json-renderers-guard to ensure safe, type-checked execution.

Step 2

VDOM Instruction Engine

Translates SSOT columns and data through json-renderers-run-instructions and applies feature flags via run-options.

Step 3

Direct DOM Mount

Mounts the compiled Virtual JSON DOM tree via @keshavsoft/json-to-dom and registers to globalThis.ks.

Quick Start

1. Installation
npm install json-renderers-from-instructions-collection
2. Render in 1 Statement
import render from "json-renderers-from-instructions-collection";

// Single Source of Truth
const columns = [
    { field: "itemName", displayName: "Item Name", type: "string" },
    { field: "category", displayName: "Category", type: "string" },
    { field: "baseUnit", displayName: "Base Unit", type: "string" }
];

const data = [
    { itemName: "Rice Raw Non-Basmathi", category: "Grains", baseUnit: "Kgs" },
    { itemName: "Cooking Oil Sunflower", category: "Oils", baseUnit: "Litres" }
];

// Single Statement Execution
render({
    data,
    columns,
    targetHtmlId: "dom-render-container",
    appendPosition: "replace",
    renderers: [
        { type: "form.simple", options: {} },
        { 
            type: "table.simple", 
            options: { showSerial: true, showSearch: true, showOptions: true } 
        }
    ]
});
